Starting skills
A roguelike character levels to 20 and is offered 3 skills at each level-up, keeping one — on top of whatever its preset already knows, which differs from character to character. Set that count here and the build has room for it. Click a skill to add it as your next pick; click it again, or a row in the build list, to take it back off.

Tier roll

At level
The game's own TierNChanceNodes, read out of its settings asset: one 1–100 roll is tested against each threshold in turn, highest tier first. Tier 3 cannot appear before level 3, tier 4 before level 6, or tier 5 before level 11.

Per-tier maximums

The game walks the rolled tier down one step at a time while that tier is already full (TierLimitRulePassed). Blank means no cap, which is what the game currently ships: MaximumSkillsPerTierSettings is empty, so no tier is ever capped. These are here to model a build under a cap, not to describe one.
